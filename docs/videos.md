# Explainer videos

A series of short videos on the [FAIR Enough](https://www.youtube.com/channel/UCMYMOF2sZTVQq5P_41LYc7A) YouTube channel walks through FDPneo, from what it is to running it in production. Each video is three to seven minutes long, has closed captions in English and Brazilian Portuguese, and matches a section of this documentation.

| # | Video | Documentation |
|---|---|---|
| 1 | What is FDPneo? | [About FDPneo](about/index.md) |
| 2 | Local deployment in one command | [Local deployment](deployment/local.md) |
| 3 | Browsing, search and SPARQL | [Browsing, search and SPARQL](usage/browsing-and-search.md) |
| 4 | Publishing metadata as a steward | [Publishing metadata](usage/publishing-metadata.md) |
| 5 | Schemas with the visual SHACL editor | [Schemas and resource types](usage/schemas.md) |
| 6 | Access policies with ODRL, and licenses | [Access policies](usage/policies.md), [Licenses](usage/licenses.md) |
| 7 | Users, settings, tokens and the API | [Users](usage/users.md), [Settings](usage/settings-and-metrics.md), [API usage](api/index.md) |
| 8 | Backup, restore and updates | [Backup and restore](deployment/backup-and-restore.md), [Updates](deployment/updates.md) |
| 9 | Agent access through MCP | [MCP bridge](agents/mcp.md) |
| 10 | Production deployment with TLS | [Production deployment](deployment/production.md) |

All videos are collected in the playlist [FDPneo, an AI-developed FAIR Data Point](https://www.youtube.com/playlist?list=PLD9zjao_DDZc). Links to the individual videos will be added here as they are published.
